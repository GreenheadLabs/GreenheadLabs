Greenhead Labs LLC is a Wyoming company that builds decentralized XRPL products, software infrastructure, and on-chain identity. Public pages do not ask visitors for wallets or keys. The company does **not** handle customer funds or request customer information.

It is a **private company**. It does **not** offer investment products, financial services, securities, or custodial services.

## Products

Focused software for decentralized infrastructure, XRPL data, and internet-native payments. Source: [greenhead.io/products](https://greenhead.io/products).
